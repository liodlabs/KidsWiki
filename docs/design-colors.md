# 키즈위키 색상표 — 페이퍼 · 잉크

부모가 오래 읽는 지식 서비스에 맞춰 따뜻한 종이색 지면과 잉크색 행동을 중심으로 구성한다. 테라코타는 라벨·포커스·작은 안내 영역에 쓴다. 키위 로고의 초록은 브랜드 식별을 맡으며, 넓은 배경이나 모든 링크에 반복하지 않는다.

## 검토한 방향

아래는 참고 자료의 원칙을 키즈위키에 맞춰 해석한 자체 팔레트다.

| 방향 | 밝은 지면 | 주요 행동 | 보조 강조 | 판단 |
| --- | --- | --- | --- | --- |
| 페이퍼 · 잉크 | `#F7F5F1` | `#34312E` | `#9B5038` | 적용. 읽기 편한 중립 지면과 가족 서비스의 온기를 함께 표현한다. |
| 쿨 라이브러리 | `#F5F7FB` | `#2C4262` | `#7290C4` | 정보 서비스의 정돈된 인상은 강하지만 다소 차갑다. |
| 소프트 클레이 | `#FCF5F1` | `#4B3330` | `#BE7370` | 부드럽지만 장문 위키 전체에 적용하면 장식적인 인상이 커진다. |

## 적용 색상과 역할

| 역할 | 밝은 화면 | 다크 화면 | 사용처 |
| --- | --- | --- | --- |
| 페이지 지면 | `#F7F5F1` | `#1C1B1A` | 전체 배경 |
| 카드·입력 | `#FFFDFA` | `#272523` | 문서, 검색창, 메뉴 |
| 안내 표면 | `#EEEAE3` | `#302D29` | 홈 히어로, 목차 |
| 본문 | `#2B2926` | `#F0EBE4` | 제목, 긴 글 |
| 보조 글자 | `#6B655D` | `#B8AFA5` | 설명, 시간, 도움말 |
| 주요 행동 | `#34312E` | `#EEE7DD` | 검색 버튼, 링크, 활성 상태 |
| 행동 위 글자 | `#FFFDFA` | `#292522` | 채운 버튼·배지의 글자 |
| 테라코타 강조 | `#9B5038` | `#E1AC8D` | 짧은 라벨, 키보드 포커스 |
| 작은 따뜻한 표면 | `#F3E5DA` | `#392D27` | 기여 안내 |
| 구분선 | `#DFD8CF` | `#44403B` | 카드 경계, 목록 구분 |

밝은 화면과 다크 화면에서 색의 역할은 동일하다. 다크 화면의 채운 버튼은 밝은 종이색 배경과 어두운 잉크색 글자로 대비를 확보한다. 주제 아이콘의 작은 파스텔 표면과 성공·오류 등 의미가 있는 상태색은 별도로 유지한다.

## 참고한 기준

- [Oil UI](https://github.com/oil-oil/oil-ui): 제품과 독자에 맞는 시각적 방향, 색이 차지하는 면적, 실제 화면 비교와 불필요한 강조 줄이기.
- [Transitions.dev](https://github.com/Jakubantalik/transitions.dev): 조용한 기본 상태와 분명한 hover·pressed·focus 피드백. 이번 변경은 기존 모션을 유지하며 색의 대비를 정리한다.
- [Lucian UX/UI Prompt](https://lucianlabs.dev/uxui-prompt/): 중립적인 갤러리 지면, 컴포넌트 안에 제한된 색, 밝은·다크 역할 쌍. 실제 화면의 색과 구조를 확인해 해석했다.
- `ui-ux-pro-max`: Knowledge Base/Documentation, Minimalism & Swiss Style 결과에서 읽기·검색 중심 구성과 중립색·대비 기준을 참고했다. 자동 추천 색을 그대로 복제하지 않는다.

## 구현

기본 선택 스킨은 `scripts/themes/kiwi-flesh.mjs`에 정의하며, 기존 사용자 설정을 보존하기 위해 내부 저장 키를 유지한다. 표시 이름은 **페이퍼 · 잉크**다. `public/css/design.css`에서 안내·기여 표면을 해당 역할 토큰에 연결하고, Bootstrap의 기본 파란 강조도 위키의 주요 행동색을 따르게 한다. 다른 선택형 스킨은 기존 팔레트를 유지한다.

## 검증

밝은·다크 홈에서 라벨, 설명, 버튼, 헤더, 기여 안내 등 주요 글자/표면 7쌍을 실제 브라우저의 계산된 색으로 확인했다. 최소 대비는 밝은 화면 **4.67:1**, 다크 화면 **6.15:1**이었다. 390px 모바일 홈과 검색 화면에서 가로 넘침 없이 표시됨을 확인했다. 이 검증은 전체 서비스의 접근성 인증을 의미하지 않는다.
